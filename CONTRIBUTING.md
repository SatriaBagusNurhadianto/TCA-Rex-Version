Terima kasih sudah mau berkontribusi! Panduan singkat:

1. Buat issue jika menemukan bug atau ingin fitur baru.
2. Buat branch bernama fix/ atau feat/ dari main.
3. Lakukan perubahan, jalankan npm ci dan npm test terlebih dahulu.
4. Buat PR ke main, sertakan deskripsi perubahan dan testing yang dilakukan.

Etika & Legal:

Jangan gunakan tool ini untuk aktivitas ilegal.
